# Rollout gates

- [ ] Both blinded founder reviews imported; disagreements adjudicated before unblinding.
- [ ] At least one standard and premium production route passes print/rights/territory gates.
- [ ] Physical DTF samples documented on the actual garment, including wash/press evidence.
- [ ] Usage exports/receipts reconcile all experiment charges; unknown items resolved.
- [ ] Accepted-session costs include processing, storage, prompt agent and funding/payment fees.
- [ ] Founders choose model tiers, credit denomination, pricing, download rights and redemption cap.
- [ ] SDK 7 / Workflow 5 integration smoke passes in a separate branch/module; native contracts preserved.
- [ ] Neon idempotency/outbox and append-only wallet invariants tested before financial writes.
- [ ] R2 private-asset lifecycle, licensed references and metadata/derivative rules tested.
- [ ] Shadow evaluations precede feature-flag launch; no customer charge in shadow mode.
- [ ] Cost, success, latency, unknown-request and print-rejection dashboards have alert owners.
- [ ] Outages/price changes invalidate stale qualification; bounded explicit fallbacks rehearsed.
- [ ] Rollback disables the generation route without discarding job/charge evidence.

Resume the six-phase venture plan after founder review. Re-run only if evidence is inconclusive or models/interfaces materially change. Keep manufacturing/export, naming/trademark and full-order margins as separate workstreams.

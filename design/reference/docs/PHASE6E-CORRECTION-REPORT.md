## Local adapter deviations and limits

1. Companion types are unimplemented proposed interfaces. Local schemas demonstrate rejection but do not replace server ownership, cryptographic quote validation, Medusa authority, ACID ledger or staff authorization. PE6-16 passes a local guard simulation; real server-side pricing/shipping and stale Medusa price rejection remain NOT_RUN.
2. Internal mutable review model is deliberately separate from public projections. Model can retain an invalid editable draft for inspection; its public EditorDraft projection rejects invalid bounds and freeze remains blocked. Frozen review reads the immutable snapshot only.
3. Frozen proof is a two-page immutable overlay set, hashed as front SVG + newline + back SVG. Each SVG records the unchanged garment-base SHA256. Display uses the original garment base and correct front/back crop beneath this exact frozen overlay; it does not render draft geometry. Paid composition mock exports preserve both independent front and back artwork pages and exclude garment photography. Illustrative SVG output embeds the licensed Archivo font; it is not a qualified print renderer or manufacturing file.
4. The single configured mock garment variant is synthetic black oversized S. Review binds this frozen variant; other size options are disabled rather than silently changing a quote. Real SKU/profile, supported zones, calibrated renderer/PPI/color/price and shipping remain blocked.
5. Outputs and entitlements persist in the local tab's validated session fixture only. Customer upload bytes are ephemeral and not included in the release. Owner urn/subject, API-shaped download routes, credits, TEST currency, policy identifiers and approvals are synthetic. No real auth endpoint or token is invented. Guest original retrieval stays free; this is not durable authentication or a production capability.
6. Remedy completion records one separate replacement-service reference, not an automatically usable final/export right. Only reviewer simulation controls can advance approval; production caps, roles, consent, notices, SLA and legal gates remain BLOCKED. Private authorization fields never enter public remedy projections.
7. SHA256 manifest and outer archive checksum seal integrity. The inputs supply checksums, not an externally trusted public-key signature; no certified digital signature is claimed.
8. Historical docs, tests/baseline and exports supplied by 1.1 are retained for provenance; their earlier acceptance statements are historical. This report and PE6-COVERAGE.csv govern 1.1.1. Production acceptance matrix in docs/technical is untouched. Remote CI NOT_RUN. No production performance/cost or commerce reconciliation is claimed.
